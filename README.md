# KKU Student IT Help-Desk Tickets: Demand, Response Time and SLA Performance

Individual project for **2323 CIS – Introduction to Data Science** (King Khalid University, College of Computer Science).

## 1. Question
Which departments and issue categories generate the most help-desk tickets, how does weekly demand change over the semester, and are tickets resolved within their service-level (SLA) targets?

## 2. Data
| File | Format | Description |
|---|---|---|
| `data/raw/helpdesk_tickets_raw.csv` | CSV | 645 raw ticket rows (messy: duplicates, mixed date formats, inconsistent labels, missing values, free-text notes) |
| `data/raw/departments.json` | JSON | Department code, name, college, staff count |
| `data/raw/sla_targets.xlsx` | Excel | SLA hours per priority |
| `data/processed/helpdesk_clean.csv` | CSV | Final analysis-ready dataset (620 rows, 25 columns) |

> **The data is simulated** (fixed random seed `2323`, generated by the first cells of the notebook) to mimic a real help-desk export. It contains no real personal data. Source/access date: generated 2026-11-08.

## 3. How to reproduce
1. Open `notebooks/analysis.ipynb` in Google Colab or Jupyter (Python 3, `pip install -r requirements.txt`).
2. *Runtime → Run all*. If the raw files are missing the notebook regenerates them.
3. Outputs: `data/processed/helpdesk_clean.csv` and four figures in `outputs/figures/`.

## 4. Data preparation steps (course techniques used)
- **Cleaning:** duplicates, label standardization, type conversion, documented handling of missing values.
- **Regular expressions:** phone numbers, room codes, ticket number, e-mail validation and domain.
- **Merge:** tickets + departments (JSON) + SLA targets (Excel) with `validate` and `indicator`.
- **Transformation:** SLA flag, hours-vs-SLA ratio, resolution bands (`pd.cut`).
- **Aggregation / pivot:** by category, department x category, per-staff demand, SLA compliance.
- **Time series:** weekly resampling, 4-week rolling mean, weekday pattern.

## 5. Main results
- WiFi (26.9%) and LMS (21.0%) account for about 48% of all tickets.
- Demand peaks in the exam period (busiest week ending 2026-04-26: 54 tickets).
- Median resolution times are inside SLA, but only about 68-71% of tickets meet the target at each priority level.
- Computer Science and Information Systems have the highest demand per staff member.

## 6. Limitations
Simulated data (method demonstration, not real KKU performance); missing priorities set to Medium; tickets with unknown resolution time excluded from time statistics; slash dates read as day/month/year; no statistical testing.
